## Os significados físicos de U
<p class="jt">
  É possível interpretarmos o significado físico da energia interna (ou a variação dela) de algumas formas. Inicialmente, a variação de energia interna foi definida como o trabalho adiabático realizado em um determinado processo. Tal interpretação está de acordo com a equaḉão da 1ᵃ. Lei da Termodinâmica (<a href="../A7/#TC7.5" style="color: blue; font-style: italic;">TC7.5</a>). Caso não haja calor, então a variação da energia interna será o trabalho realizado no processo, que é adiabático. Contudo, podemos pensar em outro caminho, um pelo qual não há trabalho realizado (a volume constante, por exemplo). Neste caso, a variação de energia interna será igual ao calor trocado no processo, como mostrado pela equação <a href="../A7/#TC7.10" style="color: blue; font-style: italic;">TC7.10</a>. Essa definição é de grande utilidade em sistemas a volume constante pois o calor, que é uma função de caminho, será igual a variação de energia interna, que é uma função de caminho! Contudo, em química, boa parte dos processos realizados em laboratório não ocorrem a volume constante, mas sim a <b>pressão constante</b>. Neste caso, como o calor é função de caminho, o seu valor será diferente daquele obtido por um caminho a volume constante. Neste caso, podemos imaginar que seria de grande utilidade termos outra função de estado que fosse igual ao calor trocado em um processo, assim com a energia interna, mas a pressão constante.
</p>

<p class="jt">
  Antes disso, vamos introduzir mais uma forma de definirmos a energia interna. Ela pode ser entendida como a soma da energia cinética média dos sistema ($\langle K \rangle$) e da energia potencial ($E_p$) das partículas do sistema - ou seja, a energia total do sistema. Escrevemos, então:
</p>

<div id="TC10.1" class="mathbox-wrapper">
  <div class="mathbox">
    $$U = \langle K \rangle + E_p$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: blue;">TC10.1</span>
  </div>
</div>

<p class="jt">
  Vamos considerar um gás ideal, no qual $E_p = 0$. Daí, podemos definir que $U = \langle K \rangle$. Considerando a equação <a href="../A2/#TC2.4" style="color: blue; font-style: italic;">TC2.4</a>, que foi obtida para um gás ideal monoatômico (sem estrutura interna), teremos que $U = \langle K \rangle = \frac{3}{2}nRT$ e, neste caso, toda a energia trocada na forma de calor se converterá em alteração na temperatura. Como $V$ e $n$ são fixos, caso $T$ varie, então $p$ irá aumentar ou diminuir de acordo com a variação de $T$, pois $pV = nRT$. Também notamos que a capacidade térmica de um gás monoatômico ideal, definida pela equação <a href="../A7/#TC7.11" style="color: black; font-style: italic;">TC7.11a</a>, fornecerá $\bar C_V = \frac{3}{2}R$, o mesmo resultado observado experimentalmente, justificando a nossa definição acima de $U$ (<a href="#TC10.1" style="color: blue; font-style: italic;">TC10.1</a>).
</p>

## O calor trocado em processos a pressão constante: a entalpia, $H$

<p class="jt">
  Em processos a pressão constante, o calor não será exatamente igual à variação de energia interna, pois parte da energia fornecida através de calor não será convertida em energia interna, mas sim em trabalho de expansão. Se não podemos usar a energia interna como forma de determinar o calor total que foi fornecido (ou liberado) para o sistema, qual função pode ser utilizada? A partir da 1ᵃ. Lei da Termodinâmica, podemos escrever, para um processo a pressão constante e com $p_{ext} \approx p$:
</p>

<div id="TC10.2" class="mathbox-wrapper">
  <div class="mathbox">
    $$ đq = dU - đw \\
    đq = dU +p_{ext} dV \\
    đq = d(U + pV)\\
    \color{red}{\boldsymbol{đq = dH = d(U + pV)}}\\
    \color{blue}{\boldsymbol{H = U + pV}}$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: red;">TC10.2a</span>
    <span style="font-weight: bold; color: blue;">TC10.2b</span>
  </div>
</div>

<p class="jt">
e definimos uma nova função, a <b>entalpia</b>, <b>$H$</b>. Essa nova função também é uma função de estado, como U: ela é a soma de uma função de estado ($U$) com o produto de outras duas funções de estado ($p$ e $V$). Assim como no caso de $U$, podemos escrever o diferencial total para esta função:
</p>

<div id="TC10.3" class="mathbox-wrapper">
  <div class="mathbox">
    $$ dH = d(U + pV) = dU + d(pV) \\
    dH = dU + pdV + Vdp \\
    dH = TdS - pdV + pdV + Vdp\\
    \color{red}{\boldsymbol{dH = TdS + Vdp}}\\
    \color{blue}{\boldsymbol{\left(\frac{\partial H}{\partial S} \right)_p = T \: ; \: \left(\frac{\partial H}{\partial p} \right)_S = V}}$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: red;">TC10.3a</span>
    <span style="font-weight: bold; color: blue;">TC10.3b</span>
  </div>
</div>

<p class="jt">
e escrevemos o <b>diferencial total</b> de $H$ em função de $S$ e $p$, suas variáveis naturais, além de termos definido as derivadas parciais de $H$ com relação a essas variáveis. Ainda, seria possível fazer uma análise de convexidade/concavidade de $H$ de maneira semelhante à feita para $U$. O resultado de tal análise seria que $H$ é convexa com relação à entropia (assim como $U$), mas côncava com relação a $p$ - ou seja, no ponto de equilíbrio de um sistema a $S$ e $p$ constantes, $H$ é um <b>ponto de cela</b>. A definição de $H$ na equação <a href="#TC10.2" style="color: blue; font-style: italic;">TC10.2b</a> é conhecida na ciência e engenharia desde meados do século $\mathrm{XIX}$, pois a equação <a href="#TC10.2" style="color: red; font-style: italic;">TC10.2a</a> deixa claro que, a pressão constante, $dH = TdS = đq_{rev,p}$. De forma mais geral, $\Delta H = q_p$, ou seja, a variação de entalpia é igual ao calor trocado em um processo realizado a pressão constante - a grandeza que estávamos em busca. Apesar de já ser conhecida, as bases teóricas para definí-la de forma rigorosa foram dadas mais tarde por J. W. Gibbs.
</p>

<p class="jt">
  Para a criação desta variável, $H$, Gibbs utilizou um método matemático conhecido como <b>transformada de Legendre</b>. Esse método permite a criação de uma nova função, a partir de uma primeira, trocando as variáveis da função. Como vimos, $U=U(S,V)$, enquanto $H=H(S,p)$. Ao analisarmos a função $U$, podemos dizer que as variáveis $V$ e $-p$ são <b>variáveis conjugadas</b>, ou seja, uma variável multiplica o diferencial da outra na equação diferencial de $U$ (<a href="../A9/#TC9.1" style="color: blue; font-style: italic;">TC9.1</a>). Para criar a nova função ($H$), basta subtrairmos da função original ($U$) o produto das variáveis conjugadas que desejamos trocar ($V$ e $-p$), ou seja, $H = U - (-pV) = U + pV$. O resultado de tal processo é a equação <a href="#TC10.2" style="color: blue; font-style: italic;">TC10.2b</a>! (Nota: essa definição é, na realidade, o <b>negativo</b> da transformada de Legendre). Ou seja, a entalpia é a transformada de Legendre de $U$, passando de $V$ para $-p$. Nesse processo, a nova função mantém a convexidade em $S$, mas passa a ser côncava para a nova variável, $-p$. Isso significa que $H$ é um <b>ponto de sela</b> com relação a $S$ e $-p$, suas variáveis.
</p>

### A capacidade térmica a pressão constante

<p class="jt">
  Assim como fizemos com $U$, podemos manipular a equação <a href="#TC10.2" style="color: red; font-style: italic;">TC10.2a</a> para estabelecermos uma relação direta entre $H$ e $q$. A pressão constante:
</p>

<div id="TC10.3" class="mathbox-wrapper">
  <div class="mathbox">
    $$\color{blue}{\boldsymbol{dH = đq_p}}$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: blue;">TC10.3</span>
  </div>
</div>

<p class="jt">
e, a partir daí, podemos definir uma grandeza que relacione a quantidade de energia fornecida/retirada com a variação de temperatura em um processo a pressão constante. Essa nova grandeza será uma capacidade térmica, também, assim como $C_V$. Contudo, ela não pode ser a mesma. Por quê? O motivo é simples: discutimos como o calor, assim como o trabalho, é uma função de caminho. Isso faz com que $\Delta U$ não possa ser igual a $\Delta H$. Logo, a constante de proporcionalidade também precisa ser diferente. Daí, podemos definir:
</p>

<div id="TC10.4" class="mathbox-wrapper">
  <div class="mathbox">
    $$ C_p(T) = \lim_{\Delta T \to 0} \left(\frac{q_p}{\Delta T}\right) \\
    \color{black}{\boldsymbol{C_p(T) = \left( \frac{\partial H}{\partial T} \right)_p}} \\
    \color{red}{\boldsymbol{\bar C_p(T) = \left( \frac{\partial \bar H}{\partial T} \right)_p}} \\
    \color{blue}{\boldsymbol{d \bar H = \bar C_p(T) dT}}$$
  </div>
  <div class="eq-numbers">
    <span style="font-weight: bold; color: black;">TC10.4a</span>
    <span style="font-weight: bold; color: red;">TC10.4b</span>
    <span style="font-weight: bold; color: blue;">TC10.4c</span>
  </div>  
</div>

<p class="jt">
  No mesmo espírito do que foi feito para $U$, chamamos aqui $C_p(T)$ de <b>capacidade térmica a pressão constante</b> de um sistema. A última equação (<a href="#TC10.4" style="color: blue; font-style: italic;">TC10.4c</a>) é válida para a) processos a pressão constante, e/ou; b) gases ideais - que também será demonstrado. Assim como $C_V(T)$, $C_p(T)$ também é função exclusiva da temperatura do sistema. Como dito anteriormente, os valores de $C_V$ para gases são dependentes da geometria molecular em grande parte das vezes. Experimentalmente, foi observado que $C_p$ também é, e os valores podem ser aproximados da seguinte forma: para gases monoatômicos, $\bar C_p \approx 20,78 J \cdot K \cdot mol^{-1} = \frac{5}{2}R$. Já moléculas lineares possuem $\bar C_p \approx 29,10 J \cdot K \cdot mol^{-1} = \frac{7}{2}R$, e, finalmente, moléculas não lineares geralmente possuem $\bar C_p \approx 33,26 J \cdot K \cdot mol^{-1} = 4R$. Ressaltamos que diversas moléculas não seguem essa regra, assim como para $C_V$. Com os dados experimentais fornecidos aqui, uma relação entre $C_p$ e $C_V$ pode ser elaborada:
</p>

<div id="TC10.5" class="mathbox-wrapper">
  <div class="mathbox">
    $$\color{blue}{\boldsymbol{\bar C_p - \bar C_V = R}}$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: blue;">TC10.5</span>
  </div>
</div>

<p class="jt">
  A equação <a href="#TC10.5" style="color: blue; font-style: italic;">TC10.5</a> diz que a capacidade térmica de gases é sempre maior quando o processo é realizado a pressão constante do que quando o processo é conduzido a volume constante. Qual é a origem de tal relação? Podemos analisar tal resultado de duas formas. A primeira, é a matemática. A partir da equação <a href="#TC10.2" style="color: blue; font-style: italic;">TC10.2b</a>, podemos derivar os dois lados da expressão com relação a temperatura, mantendo a pressão constante. Daí, desenvolvemos, para gases ideais:
</p>

<div id="TC10.6" class="mathbox-wrapper">
  <div class="mathbox">
    $$ \left( \frac{\partial H}{\partial T} \right)_p = \left( \frac{\partial U}{\partial T} \right)_p + \left( \frac{\partial nRT}{\partial T} \right)_p \\
    \color{red}{\boldsymbol{C_p = C_V + nR}} \\
    \color{blue}{\boldsymbol{\bar C_p - \bar C_V = R}}$$
  </div>
  <div class="eq-numbers">    
    <span style="font-weight: bold; color: red;">TC10.6a</span>
    <span style="font-weight: bold; color: blue;">TC10.6b</span>
  </div>
</div>

<p class="jt">
e as duas últimas equações foram obtidas considerando que $pV = nRT$ e que $\left( \frac{\partial U}{\partial T} \right)_p = \left( \frac{\partial U}{\partial T} \right)_V = C_V$. Esta última relação será demonstrada verdadeira, para gases ideais, mais adiante. A segunda forma de analisar a relação entre $C_p$ e $C_V$ é do ponto de vista físico. Vamos considerar um sistema formado por $n$ mols de um gás ideal, ocupando um volume $V$, em equilíbrio. Agora, vamos inserir energia neste sistema, na forma de calor, a um volume fixo. Ao fazermos isso, a energia interna do sistema deverá aumentar na mesma quantidade de energia que foi fornecida, já que não houve trabalho (<a href="../A7/#TC7.5" style="color: blue; font-style: italic;">TC7.5</a>) (consideramos, aqui, que não há dissipação de energia). Como o gás é ideal, então isso será transformado em aumento de energia cinética, ou seja, um aumento na temperatura do sistema. Mas e para um processo a pressão constante? Vamos considerar o mesmo sistema inicial do caso anterior, mas com o gás confinado em um êmbolo com um pistão móvel que pode controlar a pressão do sistema. Neste caso, a energia fornecida na forma de calor será convertida em aumento de temperatura também. Contudo, diferentemente do caso anterior, como a pressão do sistema também aumenta, haverá uma expansão do gás até que $p = p_{ext}$. A consequência disso é que parte da energia que é fornecida ao sistema na forma de calor será transformada em trabalho. Logo, nem toda a energia fornecida será convertida em aumento de energia cinética (temperatura). Finalmente, concluímos que para haver um aumento na temperatura igual ao sistema a $V$ constante, precisaremos de <b>mais</b> energia a $p$ constante, já que parte da energia será utilizada para realizar trabalho. Logo, $C_p \ge C_V$!
</p>

    // 3. Animation Engine
    function initJouleThomson() {
      const pistonLeft = document.getElementById('piston-left');
      const pistonRight = document.getElementById('piston-right');
      const divider = document.getElementById('divider');
      const chamberWall = document.getElementById('chamber-wall');
      const gasLeft = document.getElementById('gas-left');
      const gasRight = document.getElementById('gas-right');
      const playBtn = document.getElementById('jt-play-btn');
      const resetBtn = document.getElementById('jt-reset-btn');

      const required = { 'piston-left': pistonLeft, 'piston-right': pistonRight, 'divider': divider, 'chamber-wall': chamberWall };
      let missing = false;
      for (let id in required) {
        if (!required[id]) {
          console.error('Joule-Thomson Error: chamber.svg is missing element with id="' + id + '"');
          missing = true;
        }
      }
      if (missing) return;

      const boxPistonLeft = pistonLeft.getBBox();
      const boxPistonRight = pistonRight.getBBox();
      const boxDivider = divider.getBBox();
      const boxWall = chamberWall.getBBox();

      const maxCompressLeft = boxDivider.x - (boxPistonLeft.x + boxPistonLeft.width);
      const wallRightEdge = boxWall.x + boxWall.width;
      const pistonRightEdge = boxPistonRight.x + boxPistonRight.width;
      const maxExpandRight = (wallRightEdge - pistonRightEdge) - 5;

      const initialGasLeftWidth = gasLeft ? gasLeft.getBBox().width : 0;
      const initialGasRightWidth = gasRight ? gasRight.getBBox().width : 0;
      const initialGasLeftX = gasLeft ? (parseFloat(gasLeft.getAttribute('x')) || gasLeft.getBBox().x) : 0;

      let progress = 0;
      let isPlaying = false;
      let animFrameId = null;

      function render(p) {
        const leftShift = p * maxCompressLeft;
        const rightShift = p * maxExpandRight;
        pistonLeft.setAttribute('transform', 'translate(' + leftShift + ', 0)');
        pistonRight.setAttribute('transform', 'translate(' + rightShift + ', 0)');
        if (gasLeft) {
          if (gasLeft.tagName.toLowerCase() === 'rect') {
            gasLeft.setAttribute('x', initialGasLeftX + leftShift);
            gasLeft.setAttribute('width', Math.max(0, initialGasLeftWidth - leftShift));
          } else {
            const scaleL = Math.max(0, (initialGasLeftWidth - leftShift) / initialGasLeftWidth);
            gasLeft.setAttribute('transform', 'translate(' + leftShift + ', 0) scale(' + scaleL + ', 1)');
          }
        }
        if (gasRight) {
          if (gasRight.tagName.toLowerCase() === 'rect') {
            gasRight.setAttribute('width', initialGasRightWidth + rightShift);
          } else {
            const scaleR = (initialGasRightWidth + rightShift) / initialGasRightWidth;
            gasRight.setAttribute('transform', 'scale(' + scaleR + ', 1)');
          }
        }
      }

      function step() {
        if (!isPlaying) return;
        if (progress < 1) {
          progress += 0.005;
          if (progress > 1) progress = 1;
          render(progress);
          animFrameId = requestAnimationFrame(step);
        } else {
          isPlaying = false;
          if (playBtn) playBtn.innerText = "Play";
        }
      }

      if (playBtn) {
        playBtn.addEventListener('click', function() {
          if (progress >= 1) progress = 0;
          isPlaying = !isPlaying;
          playBtn.innerText = isPlaying ? "Pause" : "Play";
          if (isPlaying) { step(); } else { cancelAnimationFrame(animFrameId); }
        });
      }

      if (resetBtn) {
        resetBtn.addEventListener('click', function() {
          isPlaying = false;
          cancelAnimationFrame(animFrameId);
          progress = 0;
          render(0);
          if (playBtn) playBtn.innerText = "Play";
        });
      }
    }
  })();
</script>
